# Portfolio Calculator

A responsive portfolio calculator built with HTML, CSS, and JavaScript. The project focuses on a polished interface, useful calculator features, accessible controls, persistent history, and safer expression handling without `eval`.

## Highlights

- Modern app-style calculator layout with dark and light themes
- Mouse and keyboard input support
- Clear display state, expression preview, percent handling, `00`, delete, and divide-by-zero feedback
- Calculation history saved in the browser
- Advanced actions for square root, square, reciprocal, sign toggle, and copy result
- Semantic HTML with labelled controls for better accessibility
- Plain static files, so it can be hosted easily on GitHub Pages or Netlify

## Run Locally

Open `index.html` in a browser, or serve the folder locally:

```bash
python -m http.server 4173
```

Then visit `http://127.0.0.1:4173`.
